# Roadmap

M0: independent repositories, standards/governance, health shell and initial local integration. Its PRs remain subject to human review.

M1 (authorized): PostgreSQL project workspace, project-owned conversations, isolated LiteLLM gateway, OpenAI/Anthropic/Ollama adapters, explicit model routing and streamed Angular AI Chat Studio. See M1 acceptance evidence; implementation is not autonomous agent execution.

M2 (authorized implementation candidate): bounded LangGraph PM via existing Gateway, durable requirements/PRD revisions, stories/traceability/quality, human approval controls and Angular Requirements Studio. Local acceptance passes; Sourcery/final CI, human merges and post-merge milestone acceptance remain pending. See docs/milestones/M2_HANDOFF.md.

Later: Temporal workflows, additional agent roles, scoped isolated execution workers, independent QA/security loops, deployment approvals, cloud/region selection and enterprise integrations. No later milestone is implemented or authorized by M1.
