### Operations: important lifecycle mismatch

Requirements and architecture operations are server-owned tasks whose observers can disconnect. Durable records and session claims support same-key replay; failure/cancellation requires an explicit retry with a new key. The web tracker polls persisted status across navigation/reload. Allowed actions are `cancel`, `retry`, `open_result`; the project activity list contains only requirements/architecture and at most 100 newest records (E10).

These are persisted outcomes, not a durable workflow engine. Tasks execute in one Project Service process. Startup/shutdown marks unfinished work `failed` with `error_code=INTERRUPTED`; it does not resume execution. Operation statuses are `running`, `completed`, `failed`, `cancelled`. Waiting for clarification is studio/session state rather than a first-class waiting operation. There is no persisted queue or generic resume action.

**Critical gap G15:** `workspace.py:generation` checks `request.is_disconnected()` and cancels on disconnect; chat uses a StreamingResponse generator. Chat history and completed versions persist, but this does not satisfy “navigating away does not lose a run” for Discovery. Global project activity omits chat runs. Reuse the durable studio pattern only after defining chat lifecycle, cancellation, partial output, replay/reattachment and authorization. Treat this as a contract/backend slice, not a visual change.

For broader cross-domain workflows, evaluate durable execution ownership, worker leases, event replay, log access/redaction/retention, pagination and cancellation races. Existing single-replica stop→migrate→start semantics must remain explicit until a separately approved change supports replicas. The design's seven visible states should map truthfully to persisted state; do not relabel `failed` as resumable or invent percentage progress.

Type/signature validation, resource-limited parsing, SSRF guard, untrusted-source delimiting, audit/retention and optional fail-closed malware scanning exist. Default malware scanning is off. Live share imports, commercial generation, OCR and office-file parsing are not established by this audit.
